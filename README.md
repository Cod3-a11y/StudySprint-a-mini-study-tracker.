📚 StudySprint

Small steps. Real progress.

StudySprint is a lightweight, beginner-friendly study task tracker built with HTML, CSS, and JavaScript. It helps students organize their daily study tasks, track their progress, and stay focused on their goals through a simple, responsive interface.

✨ Features

- ➕ Add Tasks — Create study tasks with a simple input field.
- ✅ Track Progress — Mark tasks as completed and watch your progress bar update automatically.
- 🗑️ Delete Tasks — Remove tasks you no longer need.
- 💾 Persistent Storage — Tasks are saved in your browser using "localStorage", so they remain available after refreshing the page in the same browser.
- 📱 Responsive Design — A clean, blue-and-white interface designed to work on desktop and mobile screens.
- ♿ Accessibility Features — Includes accessible labels, keyboard focus indicators, and reduced-motion support.

🛠️ Technologies Used

Technology| Purpose
HTML5| Structures the web application
CSS3| Handles styling and responsive layouts
JavaScript| Powers task management and progress tracking
Web Storage API| Saves tasks locally in the browser

🚀 Getting Started

Run Locally

1. Clone this repository or download its files.
2. Make sure "index.html", "style.css", and "script.js" are in the same directory.
3. Open "index.html" in a modern web browser.
4. Start adding and completing your study tasks!

No installation, external libraries, or build tools are required.

💡 How It Works

1. Enter a study task in the input field.
2. Click Add Task to add it to your list.
3. Check the box beside a task when you finish it.
4. Monitor your completion percentage using the progress bar.
5. Delete tasks whenever necessary.

StudySprint stores task data in your browser's local storage. Your tasks are not automatically synchronized across devices or browsers.
